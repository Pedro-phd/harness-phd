# Módulo front

Ative para interface renderizada: páginas, componentes, layout, responsividade, estados visuais, animação.

Leia só as skills cuja condição a tarefa atende. Uma tarefa pode atender várias.

## Base (instaladas pela etapa 1, pelo toolkit)

| Skill | Quando usar |
|---|---|
| `vercel-react-best-practices` | Sempre que escrever ou revisar React/Next: dados, renderização, bundle, servidor. |
| `vercel-composition-patterns` | Ao criar componentes ou mudar a API deles. |
| `web-design-guidelines` | Antes de dar como pronta qualquer mudança de UI: acessibilidade, teclado, foco, formulários, estados. |
| `shadcn` | Quando existir `components.json` ou o usuário pedir shadcn. |
| `vercel-react-view-transitions` | Quando a tarefa pedir transições entre telas ou estados com View Transitions. |
| `next-dev-loop`, `next-bundle-optimizer` | Em projeto Next.js: ver a mudança rodando no navegador; analisar ou reduzir o bundle. |

## Design e motion (deste módulo)

| Skill | Quando usar |
|---|---|
| `emil-design-eng` | Trabalho visual ou de polimento: aparência, detalhes de componente, decisões de animação. Não use em edição de front sem impacto visual. |
| `animate` | Criar uma animação ou transição nova. |
| `apple-design` | Gestos, springs, drag, swipe, sheets, interações interrompíveis. |
| `animation-performance` | Animação travando, perdendo frames, ou ao escolher propriedade/técnica por desempenho. |
| `mobile-native` | App web pensado para celular, PWA, toque, safe areas, bottom sheets. |
| `break-ui` | Componente ou tela nova que exibe dados variáveis: testar nomes longos, listas vazias, números extremos. |

## Só por comando explícito do usuário

Estas skills têm a ativação automática desligada: não entram no contexto e só rodam quando o usuário chama pelo nome ou slash command.

| Skill | Para quê |
|---|---|
| `review-animations` | Revisão rigorosa das animações. |
| `pick-ui-library` | Escolher biblioteca para uma tarefa de front. |
| `prototype` | Gerar várias versões de um componente com seletor. |
| `find-animation-opportunities` | Onde vale animar. |
| `improve-animations` | Auditoria e plano de melhoria das animações. |
| `remove-animations` | Tirar animação desnecessária quando a interface parece lenta. |
| `animation-vocabulary` | Nome certo de um efeito de animação. |
| `ask-sonner` | Dúvidas e problemas com Sonner (toasts). |
