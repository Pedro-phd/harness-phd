# Módulo debug

Ative para investigar bug, erro, falha, exceção, comportamento inesperado, regressão ou lentidão.

| Skill | Quando usar |
|---|---|
| `diagnosing-bugs` | Sempre que este módulo for ativado: reproduzir, reduzir, levantar hipóteses, instrumentar, corrigir e criar teste de regressão. |
